---

## 🧩 About

This repository is designed to teach and demonstrate the fundamental CRUD operations in **Sequelize** using MySQL (or compatible SQL DB). Whether you’re just getting started with ORMs or want quick reference code, you’ll find working examples for:

- **INSERT** → creating new records  
- **UPDATE** → modifying existing records  
- **SELECT / FIND** → querying data  
- **DELETE** → removing records  

Each example is standalone and easy to follow.

---

## ✨ Features / What You’ll Learn

- Establishing a connection to a SQL database via Sequelize  
- Defining models and schema  
- Inserting new rows (single & bulk)  
- Updating rows with conditions  
- Querying data (findOne, findAll, filters, projections)  
- Deleting with conditions  
- Handling errors and using `async/await` style  

---

## ✅ Prerequisites

Before you begin, ensure you have:

- **Node.js** (v14 or newer)  
- **npm** (or yarn)  
- A running **MySQL** (or MariaDB) server, with credentials to connect  
- Basic knowledge of JavaScript / async programming
